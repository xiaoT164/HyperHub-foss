# HyperHub 2.1.0

**HyperOS / MIUI toolkit for Xiaomi, Redmi and POCO devices**

🌐 [hyperhub.dafx.ru](http://hyperhub.dafx.ru) · 💬 [Telegram](https://t.me/HyperHubRu)

HyperHub — набор инструментов для тонкой настройки и диагностики устройств на HyperOS/MIUI.
Версия 2.1.0 — «облегчённая» сборка: убраны геймификация, индекс здоровья и лишние экраны,
бенчмарк обновлён до **HyperBench v3.5** и добавлена система сторонних модификаций **.hhopt**.

## ✨ Что нового в 2.1.0

### Удалено
- **Геймификация** — XP, уровни, серии дней, достижения и экран «Награды» полностью убраны.
- **Индекс здоровья и живой монитор** — экраны и виджеты мониторинга состояния устройства удалены.
- **Экран «Обновления»** — история версий и кнопка проверки обновлений убраны.
- **Экран «Профили»** — готовые и пользовательские профили оптимизации удалены.
- **Онбординг** — интро при первом запуске больше не показывается.

### HyperBench v3.5 (улучшенный бенчмарк, переименован из HubBench)
- **Прогрев перед каждой серией** — «холодные» прогоны гарантированно не попадают в выборку.
- **Мин/макс разброс** — вместе с медианой теперь видны min и max каждой серии.
- **Новая метрика «смешанная нагрузка»** — копирование памяти + хеширование + арифметика,
  ближе всего к реальным приложениям (браузеры, мессенджеры, архиваторы).
- **Обновлённый расчёт доверия** — штраф за нестабильность учитывает и разброс, и размах серии.
- **История прогонов** — до 20 замеров, столбчатый график, лучший результат и дельта к прошлому прогону
  (сохранена с прошлых версий).
- **Экспорт** — история бенчмарков входит в JSON-бэкап.

### Моды (.hhopt)
- **Сторонние модификации** — новый формат `.hhopt` позволяет добавлять карточки на главный экран.
- **Безопасно по дизайну** — мод не исполняет код: он только объявляет карточки, ссылающиеся
  на функции из белого списка HyperHub (`Features`).
- **Экран «Моды»** — установка через системный выбор файла, включение/выключение, удаление.
- Моды входят в экспорт/импорт бэкапа.

### Мелкое
- Обновлены версии на карточках интерфейса, экране настроек и в `versionName`.
- В настройках — «Очистить историю» вместо «Сбросить статистику».

## Формат модификаций .hhopt

`.hhopt`-файл — это **JSON-манифест** (можно упаковать в ZIP вместе с ресурсами; manifest.json
читается из корня архива). Пример:

```json
{
  "hhopt": 1,
  "id": "com.example.mymod",
  "name": "My Mod",
  "version": "1.0",
  "minAppVersion": "2.1.0",
  "author": "You",
  "description": "Adds a quick FPS-boost card to Home",
  "cards": [
    { "id": "card_fps", "title": "Разгон FPS", "subtitle": "Быстрый доступ", "feature": "fps" }
  ]
}
```

Поля `hhopt`, `id`, `name` — обязательные. `feature` — ключ из реестра `Features`
(например `fps`, `perf`, `anim`, `ram`, `net`, `batt`, `game`, `bloat`, `radio`, `cit`,
`dev`, `display`, `debug`, `labs`, `ads`, `labels`, `region`, `space`, `font`, `tg`, `donate`).
Карточка с неизвестным ключом молча не показывается — это защита от опечаток и несовместимости.
