# Формат модификаций HyperHub (.hhopt) — v1

`.hhopt` — файл сторонней модификации для HyperHub 2.1.0+. Это **JSON-манифест**:
мод описывает, какие карточки добавить в приложение, и не содержит исполняемого кода.

## Файл

Мод — это JSON-документ (или ZIP-архив с `manifest.json` в корне, если нужны ресурсы).

```json
{
  "hhopt": 1,
  "id": "com.hyperhub.demo.quicktweaks",
  "name": "Quick Tweaks Demo",
  "version": "1.0.0",
  "minAppVersion": "2.1.0",
  "author": "HyperHub",
  "description": "Что делает мод",
  "cards": [
    {
      "id": "card_demo_fps",
      "title": "Разгон FPS (мод)",
      "subtitle": "Из Quick Tweaks Demo",
      "feature": "fps"
    }
  ]
}
```

## Поля манифеста

| Поле | Обязательное | Тип | Описание |
|---|---|---|---|
| `hhopt` | да | number | Версия формата. Сейчас только `1`. |
| `id` | да | string | Уникальный идентификатор. Рекомендуется reverse-domain: `com.author.modname`. |
| `name` | да | string | Отображаемое название мода. |
| `version` | нет | string | Версия самого мода (например `1.0.0`). |
| `minAppVersion` | нет | string | Минимальная версия HyperHub, на которой мод работает. |
| `author` | нет | string | Автор. |
| `description` | нет | string | Описание для экрана «Моды». |
| `cards` | нет | array | Список карточек, которые мод добавляет на главный экран. |

## Карточки (`cards`)

| Поле | Обязательное | Тип | Описание |
|---|---|---|---|
| `id` | да | string | Уникальный внутри мода идентификатор карточки. |
| `title` | да | string | Текст карточки. |
| `subtitle` | нет | string | Подзаголовок. |
| `feature` | да | string | Ключ функции из белого списка Features (см. ниже). |

Карточка с неизвестным `feature` или пустым `title` молча не показывается — это защита
от опечаток и несовместимости версий.

## Белый список `feature`

`fps`, `perf`, `anim`, `ram`, `net`, `batt`, `game`, `bloat`, `radio`, `cit`, `dev`,
`display`, `debug`, `labs`, `ads`, `labels`, `region`, `space`, `font`, `tg`, `donate`.

Каждый ключ соответствует инструменту HyperHub: по тапу открывается его инструкция/команды.

## Безопасность

- Мод **не исполняет код**: ни reflection, ни `exec`, ни сети.
- Мод может только объявлять карточки со ссылкой на функцию из белого списка.
- Установка/удаление/вкл-выкл — через экран «Моды» в приложении.
- Установленные моды хранятся локально и входят в JSON-бэкап.
